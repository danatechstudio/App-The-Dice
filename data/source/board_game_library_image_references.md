# Board Game Library — Enriched Catalogue

> Working Markdown database derived from eight shelf photographs and an earlier preliminary inventory. Metadata is indicative, not a box-by-box verification. Ages and player counts can differ between editions. Play times are practical estimates. Do not publish uncertain identifications as confirmed holdings.

> **Image enrichment note (15 October 2026):** Each game now includes an image lookup URL, but **not** a verified direct cover-image URL. Image and thumbnail fields are intentionally marked pending rather than populated with fabricated or incorrect links. The lookup links open a BoardGameGeek search for each title. Review the exact edition before choosing artwork. If displaying images publicly, confirm reuse rights and hotlinking conditions with the source.

## Field definitions

- **Age:** approximate minimum recommended age; verify on the physical box.
- **Audience:** practical suitability labels, not publisher ratings.
- **Players:** typical supported count, sometimes dependent on edition or teams.
- **Play time:** approximate minutes excluding setup and teaching.
- **Status:** `provisional` for catalogued games; titles still require physical confirmation.
- **Copies:** not counted reliably because photographs overlap.
- **Image URL / Thumbnail URL:** direct artwork URLs to populate after source and edition verification.
- **Image lookup:** per-title search URL to locate artwork.
- **Image status:** `pending` means no direct image was verified.

## Data quality notes

This is an editorial enrichment of the preliminary visual catalogue, **not** individually verified research for every game. Several older, obscure and licensed editions have estimated metadata. Check packaging and publisher instructions before using ages or player limits as authoritative. Duplicate copies and unidentifiable boxes require a separate physical stocktake.
